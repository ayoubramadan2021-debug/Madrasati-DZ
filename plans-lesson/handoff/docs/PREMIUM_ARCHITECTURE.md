# معمارية Premium

## الدروس

المحرك الموحد للدروس يدير:

- المشاهد والصور.
- صوت الأستاذ.
- ملفات WordBoundary.
- الكاريوكي.
- التشغيل التلقائي وإعادة التشغيل.
- تقدم الدرس ونهايته.
- الانتقال إلى التمارين والاختبار والدرس التالي.

## التمارين

تدفق التمارين الموحد يدير:

- `stage`.
- اختيار المحرك المتخصص.
- تمرير `items` و`audio_base`.
- استقبال `onComplete`.
- منع الانتقال المكرر.
- شاشة الإكمال.

المحركات المتخصصة تبقى مستقلة، مثل:

- `TapSelectExerciseV2`
- `CountTapExerciseV2`
- `DragMatchExerciseV2`
- `SortSequenceExerciseV2`
- `TraceExerciseV2`
